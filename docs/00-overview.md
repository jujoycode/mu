# 00. 개요 — mu

> 無에서 시작하는 팀 내부용 미니멀 코딩 에이전트 harness
> 최종 수정: 2026-07-26 · 상태: P0·P1·P2 코드 완료, P3(실사용) 진입 (로드맵: docs/04)

## 한 줄 정의

mu는 팀 내부용 미니멀 코딩 에이전트 harness다. 범용 코딩 능력으로 경쟁하지 않고,
범용 툴(Claude Code, Pi 등)이 구조적으로 접근할 수 없는 **팀 내부 컨텍스트와 시스템**
— 내부 지식/스킬, SSH 인프라 — 에 가치를 건다.

## 이름의 의미

- **μ (micro)**: SI 접두어 10⁻⁶. "minimal"의 기호 그 자체
- **無 (mu)**: 선불교 공안에서 "질문 자체를 무효화하는 대답". 미니멀리즘 선언
- **계보**: 영감의 원천인 pi(pi.dev)의 그리스 문자 계보를 잇는다

### 이름 관련 실무 체크
- [ ] 팀 머신에서 `which mu` 확인 (mu 메일 인덱서와 바이너리 충돌 가능 — 내부 툴 기준 감수 가능한 수준)
- npm 패키지는 스코프 사용: `@team/mu` (선점 걱정 없음)
- 전역 명령 등록은 `bun link`로 빌드 스텝 없이 해결

## 영감: Pi (pi.dev)

- Mario Zechner의 MIT 오픈소스 미니멀 터미널 코딩 harness
- 코어는 read/write/edit/bash 4개 도구 + 얇은 TUI + 미니멀 루프가 전부
- 서브에이전트, 플랜 모드, 권한 게이트, MCP 등은 전부 TypeScript 확장으로 얹는 구조
- "lazy skills": 스킬당 요약 한 줄만 컨텍스트에 상주, 실제 내용은 온디맨드 로드

## mu의 차별점

Pi가 "범용 확장 생태계"라면, mu는 **우리 팀 전용 도구**에 집중한다.

1. **내부 지식/스킬 배포** — git 기반 팀 스킬 레포, lazy loading
2. **SSH 원격 실행** — 호스트 레지스트리 + 환경별 정책 + 감사 로그
